# 🔐 My Vault

A private, offline password manager extension for Chrome and Edge.
Your passwords are encrypted on your own device — nothing is uploaded anywhere.

**Developed by Arafat Ahmed** · © 2026 Arafat Ahmed. All rights reserved.

## Features
- AES-256 encrypted vault protected by your master password
- Autofill icon in login fields and "Save this login?" prompts
- Built-in 2FA (TOTP) code generator and password generator
- Import (Chrome, LastPass, Bitwarden, 1Password CSV/JSON) and export (encrypted backup or CSV)
- Backup reminders, auto-lock, light and dark theme

## Install
1. Go to **[Releases](../../releases/latest)** and download `my-vault-extension.zip`.
2. Extract it into a folder you will keep (e.g. `Documents/MyVault`).
3. Open `chrome://extensions` (Edge: `edge://extensions`) and turn on **Developer mode**.
4. Click **Load unpacked** and choose the folder that contains `manifest.json`.
5. Pin the My Vault icon, open it, and enter your **16-digit activation key**.

## Updating
Copy the new files over the **same folder** and click the reload icon on `chrome://extensions`. Loading a different folder creates a new, empty copy — export a backup first.

## Back up your vault
Your vault is stored only in this browser. Removing the extension or clearing browser data deletes it, and a forgotten master password cannot be recovered. Use **Backup → Export encrypted backup** regularly.
